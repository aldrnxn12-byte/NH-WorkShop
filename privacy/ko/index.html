개인정보처리방침 — NH Factory

시행일: 2026-09-16 (2026-09-16 개정) · View in English

이 문서는 영문 원문(Privacy Policy)의 한국어 번역본입니다. 두 문서의 내용은 같습니다.

1. 운영자

NH Factory(이하 “이 앱”)는 나흘공방(대표 방하늘)이 운영하는 Windows 데스크톱 응용 프로그램입니다.

연락처: ace@kkuming.kr · 전화 070-4517-6039

개인정보 보호책임자: 방하늘 (ace@kkuming.kr, 070-4517-6039)

2. YouTube API 서비스

이 앱은 사용자의 YouTube 채널에 영상을 업로드하기 위해 YouTube API 서비스를 사용합니다.

이 앱의 YouTube 기능을 사용하면 YouTube 서비스 약관에 동의하는 것이 됩니다.

Google이 처리하는 데이터에는 Google 개인정보처리방침이 적용됩니다: http://www.google.com/policies/privacy

3. 이 앱이 접근하는 Google 사용자 데이터와 사용 목적

  • 요청하는 범위(scope)는 youtube.upload 하나뿐입니다.
  • 사용자가 어떤 영상에 대해 “YouTube에 업로드”를 누르면, 이 앱은 그 영상 파일과 썸네일, 그리고 사용자가 화면에서 확인한 제목·설명·태그·공개 범위/예약 설정·합성 콘텐츠 공개 설정을 YouTube로 전송합니다.
  • 이 앱은 어느 채널에 업로드되는지 보여 주기 위해 사용자가 연결한 채널의 이름과 ID를 읽습니다.
  • 이 앱은 사용자의 다른 영상·댓글·분석 데이터·계정 정보를 읽거나 수정하거나 삭제하지 않습니다.
  • Google 사용자 데이터를 누구에게도 판매·공유·이전하지 않으며 광고에 사용하지 않습니다.

4. 데이터 저장 위치

  • 이 앱에는 서버가 없습니다. OAuth 토큰은 사용자 PC의 Windows 자격 증명 관리자에만 저장됩니다. 채널 이름·ID와 업로드 결과는 사용자 PC의 로컬 데이터베이스에 저장됩니다.
  • 로컬에 캐시된 YouTube 데이터(채널 이름·ID, 영상 ID)는 30일 이내에 갱신되거나 삭제됩니다.

5. 사용자가 직접 연결하는 다른 서비스

사용자가 AI 서비스(예: OpenAI, Anthropic, Google Gemini, ElevenLabs)의 API 키를 직접 입력하면, 사용자가 만드는 텍스트·이미지·음성은 사용자 PC에서 해당 서비스로 직접 전송되며 각 서비스의 약관과 개인정보처리방침이 적용됩니다. 운영자는 이 데이터를 받지 않습니다. 키는 사용자 PC의 Windows 자격 증명 관리자에만 저장됩니다.

6. Threads(Meta) API

Threads 계정 연결은 선택입니다. 연결하는 경우 앱은 아래 권한만, 아래 목적으로만 사용합니다.

  • threads_basic — 연결된 계정 정보를 읽어 「어느 계정에 연결됐는지」 화면에 보여 줍니다.
  • threads_content_publish — 사용자가 그 글의 게시 버튼을 누를 때만 게시합니다.
  • threads_keyword_search — 사용자가 입력한 주제로 공개 글을 찾아 글감 조사에 씁니다.
  • threads_read_replies — 사용자 본인 글에 달린 답글을 앱에서 보여 줍니다.
  • threads_manage_replies — 사용자가 그 답글의 버튼을 누를 때만 답글을 달거나 숨깁니다.
  • threads_manage_insights — 사용자 본인 글의 조회·반응 수를 보여 줍니다.

접근 토큰은 사용자 PC 의 Windows 자격 증명 관리자에만 저장됩니다. 운영자는 서버가 없으므로 Threads 계정 정보·글·답글·토큰이 운영자에게 전송되거나 보관되는 일이 없습니다. 자동으로, 또는 예약으로 게시·답글·삭제하는 기능은 없습니다.

연결 해제: 앱 > 설정 > Threads > 연결 해제 를 누르면 저장된 토큰이 삭제됩니다. Threads 앱 > 설정 > 계정 > 웹사이트 권한 에서도 권한을 해제할 수 있습니다. 연결 해제 안내 · 데이터 삭제 안내

NH Factory 는 Meta·Threads 와 제휴 관계가 없으며 보증을 받지 않았습니다.

7. 음성 녹음

“내 목소리” 기능을 사용하는 경우, 녹음과 음성 모델은 사용자 PC에 남습니다(ElevenLabs를 선택한 경우에는 해당 서비스의 약관에 따라 ElevenLabs로 전송됩니다). 설정에서 언제든지 삭제할 수 있습니다.

8. 권한 철회와 데이터 삭제

  • 앱 안에서: 설정 > YouTube > 연결 해제 를 누르면 저장된 토큰과 캐시된 YouTube 데이터가 삭제됩니다.
  • Google 계정에서: https://security.google.com/settings/security/permissions
  • 앱 안에서: 설정 > Threads > 연결 해제 를 누르면 저장된 Threads 토큰이 삭제됩니다. Threads 앱 > 설정 > 계정 > 웹사이트 권한 에서도 해제할 수 있습니다.
  • 앱을 제거하고 데이터 폴더를 삭제하면 로컬에 저장된 모든 데이터가 사라집니다.

9. 아동

이 앱은 아동을 대상으로 하지 않습니다.

10. 변경

변경 사항은 이 페이지에 게시하고 시행일을 갱신합니다.
