03. 음성 엔진과 채널 목소리

⏱ 10분(내려받기 포함) · 💰 0원 · ✅ 준비물: 인터넷

일본어 내레이션은 VOICEVOX Nemo 엔진이 만듭니다. 용량이 커서 설치 파일에 넣지 않고 처음 한 번 내려받습니다.

순서

  1. 1. 첫 실행 마법사 4단계 또는 설정 > 채널 목소리.
  2. 2. 엔진 내려받기 를 누릅니다(진행률이 보입니다).
  3. 3. 끝나면 음성 엔진 켜기. 상단바의 「음성」 점이 초록이 됩니다.
  4. 4. 화자 목록에서 같은 문장을 들어 보고 채널 목소리로 지정.

🔍 잘 됐는지 확인: 상단바 「음성」 이 초록이고, ③음성 단계에서 줄별 ▶ 재생이 들립니다.

🧯 막히면

증상 해결
내려받기 실패인터넷을 확인하고 다시 시도. 회사 네트워크는 차단될 수 있습니다.
「엔진을 실행하지 못했어요」백신이 막았을 수 있습니다. %LOCALAPPDATA%\NHFactory 를 예외로 추가하세요.
소리가 안 남Windows 소리 설정에서 출력 장치를 확인하세요.

🔒 크레딧 표시 의무: VOICEVOX Nemo 음성을 쓰면 영상 설명에 音声：VOICEVOX Nemo 를 넣어야 합니다. 프로그램이 자동으로 넣고, 빠지면 업로드 체크리스트에서 막습니다.
