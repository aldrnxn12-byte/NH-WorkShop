05. AI 무료 모드 (채팅 왕복)

⏱ 5분 · 💰 0원 · ✅ 준비물: ChatGPT·Claude·Gemini 중 아무 채팅 하나

키도 요금도 없이 쓰는 기본 모드입니다. 프로그램이 만든 프롬프트를 채팅에 붙여넣고, 답을 다시 프로그램에 붙여넣습니다.

순서

  1. 1. 단계 화면에서 프롬프트 복사.
  2. 2. ChatGPT 열기(또는 Claude·Gemini)로 채팅을 엽니다.
  3. 3. 채팅 입력칸에 붙여넣기(Ctrl+V) 하고 보냅니다.
  • - 사건·팩트 단계는 웹 검색을 켜 주세요(프롬프트에도 그렇게 적혀 있습니다).
  1. 4. 답이 나오면 전부 복사해서 프로그램의 「채팅이 준 답을 그대로 붙여넣으세요」 칸에 붙여넣고 확인.

🔍 잘 됐는지 확인: 「형식 확인 완료 — 이 값으로 진행합니다」 가 초록색으로 보입니다.

답이 형식에 안 맞을 때

  • - 「이 칸이 빠졌어요: …」 → 고쳐달라는 문장 복사 를 눌러 채팅에 붙여넣으세요.
  • - 「JSON 을 찾지 못했어요」 → 답을 코드블록째로(``json … ``) 통째로 복사하세요.

이미지도 무료로

장면 이미지는 직접 넣기(기본)입니다.

⚠ 한 장면 = 새 메시지 1개. 10개를 한꺼번에 붙여넣으면 AI 가 한 장에 여러 칸(콜라주) 으로
그려 줍니다. 그래서 프로그램도 한 장면씩만 복사해 줍니다.
  1. 1. ④장면에서 [다음 장면 프롬프트 복사 (1/10)] → ChatGPT 새 대화에 붙여넣기 → 이미지 1장 받기.
  2. 2. 받은 이미지를 카드에 끌어다 놓기, Ctrl+V, 또는 이미지 파일 고르기.
  3. 3. 넣으면 버튼이 자동으로 (2/10) 로 넘어갑니다. 다시 복사 → 붙여넣기를 10번 반복하면 끝.
  4. 4. 다시 만들고 싶은 장면은 그 카드를 고르고 오른쪽 [프롬프트 복사] 를 쓰세요.

어떤 이미지 도구를 쓰나요?

  • - ChatGPT 이미지 를 권합니다(워터마크 없음).
  • - Gemini 무료판은 오른쪽 아래에 반짝이 워터마크가 찍힙니다 — 영상에 그대로 들어가니 피하세요.

틀린 예 — 이렇게 나오면 다시 만드세요

  • - 한 장에 여러 칸이 나뉜 그림(콜라주·격자)
  • - 가로로 긴 그림(세로 영상에서는 위아래가 잘립니다)
  • - 오른쪽 아래에 워터마크가 찍힌 그림
  • - 앞 장면과 거의 같은 그림

프로그램이 이 네 가지를 넣을 때 자동으로 검사해서 노란 띠로 알려 줍니다(그래도 쓸 수는 있습니다).

⛔ 워터마크를 지우거나 잘라내는 기능은 만들지 않습니다.

🔒 주의: 채팅에 개인정보나 키를 붙여넣지 마세요.
