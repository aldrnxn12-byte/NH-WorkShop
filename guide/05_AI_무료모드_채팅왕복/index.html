05. AI 무료 모드 (채팅 왕복)

⏱ 5분 · 💰 0원 · ✅ 준비물: ChatGPT·Claude·Gemini 중 아무 채팅 하나

키도 요금도 없이 쓰는 기본 모드입니다. 프로그램이 만든 프롬프트를 채팅에 붙여넣고, 답을 다시 프로그램에 붙여넣습니다.

순서

  1. 1. 단계 화면에서 프롬프트 복사.
  2. 2. ChatGPT 열기(또는 Claude·Gemini)로 채팅을 엽니다.
  3. 3. 채팅 입력칸에 붙여넣기(Ctrl+V) 하고 보냅니다.
  • - 사건·팩트 단계는 웹 검색을 켜 주세요(프롬프트에도 그렇게 적혀 있습니다).
  1. 4. 답이 나오면 전부 복사해서 프로그램의 「채팅이 준 답을 그대로 붙여넣으세요」 칸에 붙여넣고 확인.

🔍 잘 됐는지 확인: 「형식 확인 완료 — 이 값으로 진행합니다」 가 초록색으로 보입니다.

답이 형식에 안 맞을 때

  • - 「이 칸이 빠졌어요: …」 → 고쳐달라는 문장 복사 를 눌러 채팅에 붙여넣으세요.
  • - 「JSON 을 찾지 못했어요」 → 답을 코드블록째로(``json … ``) 통째로 복사하세요.

이미지도 무료로

장면 이미지는 직접 넣기(기본)입니다.

  1. 1. ④장면에서 10장 프롬프트 한 번에 복사 → 채팅에서 이미지 생성.
  2. 2. 받은 이미지를 카드에 끌어다 놓기, Ctrl+V, 또는 이미지 파일 고르기.
  3. 3. 여러 장을 한 번에 넣으면 파일 이름의 숫자 순서로 자동 배치되고, 배치 확인 화면에서 끌어서 고칠 수 있습니다.

🔒 주의: 채팅에 개인정보나 키를 붙여넣지 마세요.
