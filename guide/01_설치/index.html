01. 설치하기

⏱ 5분 · 💰 0원 · ✅ 준비물: Windows 10/11 64비트 · RAM 8GB · 디스크 여유 5GB

순서

  1. 1. 받은 NHFactory-Setup-0.1.0.exe 를 두 번 누릅니다.
  2. 2. 파란 화면 「Windows의 PC 보호」 가 뜨면 → 추가 정보 → 실행.
  • - 개인이 만든 프로그램이라 코드 서명이 없어서 뜨는 경고입니다.
  1. 3. 설치 위치는 그대로 두고 설치. 관리자 권한은 필요 없습니다.
  2. 4. 끝나면 바탕화면의 NH Factory 를 실행합니다.
설치 파일 대신 압축본(zip) 을 받으셨다면: 압축을 풀고 NHFactory.exe 를 실행하면 됩니다(설치 불필요).

[화면 사진 준비 중 — SmartScreen 경고 화면]

🔍 잘 됐는지 확인: 창이 열리고 첫 실행 마법사(6단계)가 보이면 성공입니다.

🧯 막히면

증상 해결
창이 안 열리고 반응 없음WebView2 런타임이 없을 수 있습니다. 설치 파일이 자동으로 깔아 주지만 실패했다면 Microsoft 공식 페이지에서 Evergreen 부트스트래퍼를 받아 설치하세요.
백신이 파일을 지움서명이 없어 오탐이 납니다. 격리함에서 복원하고 설치 폴더를 예외로 추가하세요.
「디스크 공간이 부족합니다」5GB 이상 비우고 다시 실행하세요.

업데이트 · 제거

  • - 업데이트: 새 Setup.exe 를 그냥 실행하면 덮어 설치됩니다. 만든 영상과 설정은 지워지지 않습니다.
  • - 제거: Windows 설정 > 앱 > 설치된 앱 > NH Factory > 제거. 작업 폴더와 앱 데이터는 남습니다.

🔒 주의: 출처가 불확실한 곳에서 받은 Setup 파일은 실행하지 마세요.
