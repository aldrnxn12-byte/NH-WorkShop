06. AI 유료 모드 (API 키)

⏱ 10분 · 💰 사용한 만큼 (선불 충전 권장) · ✅ 준비물: 결제 수단

자동으로 돌리고 싶을 때만 쓰세요. 무료 모드로도 전부 됩니다.

💡 구독과 API 는 결제가 다릅니다. ChatGPT Plus 를 쓰고 있어도 API 는 따로 충전해야 합니다.

OpenAI

  1. 1. https://platform.openai.com 에 가입·로그인합니다.
  2. 2. 결제(Billing) 화면에서 선불 충전을 조금 넣습니다(소액부터).
  3. 3. API keys 화면에서 새 키를 만들고 복사합니다(키는 만든 직후에만 보입니다).
  4. 4. 설정 > AI 연결 > OpenAI 칸에 붙여넣고 저장 → 연결 테스트.
  5. 5. 같은 화면에서 월 예산 경고 금액을 정해 두세요.

Anthropic (Claude) · Google Gemini

  • - Anthropic: https://console.anthropic.com → 결제 등록 → API 키 생성 → 설정에 붙여넣기.
  • - Gemini: https://aistudio.google.com → API 키 생성 → 설정에 붙여넣기.
  • - 이미지 생성은 Claude 가 지원하지 않습니다. 장면 이미지는 OpenAI·Gemini 또는 직접 넣기를 쓰세요.

비용 감각

프로그램이 버튼 옆에 예상 비용(₩) 을 보여 줍니다. 장면 이미지가 가장 비싸고,

글(사건·대본·업로드 세트)은 편당 몇백 원 수준입니다. 실제 값은 설정의 환율·모델에 따라 달라집니다.

🔍 잘 됐는지 확인: 설정에서 「연결됨」 칩이 초록이고 모델 목록이 불러와집니다.

🧯 막히면

증상 해결
「키가 맞지 않아요」앞뒤 공백이 붙었는지 확인하고 다시 붙여넣으세요.
「잔액이 부족해요」결제 화면에서 충전하세요(구독료와 별개).
「사용량 한도에 걸렸어요」1분 뒤 다시 시도하거나 무료 모드로 바꾸세요.

🔒 주의: 키는 Windows 자격 증명 관리자에만 저장됩니다. 파일·기록·프로필 내보내기에 들어가지 않습니다. 키를 채팅·메신저로 보내지 마세요.
