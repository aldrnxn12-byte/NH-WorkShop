02. 작업 폴더와 채널 프로필

⏱ 3분 · 💰 0원 · ✅ 준비물: 없음 (프로필 파일이 있으면 같이)

작업 폴더

편마다 만든 이미지·음성·영상이 쌓이는 곳입니다. 첫 실행 마법사 2단계에서 고릅니다.

  1. 1. 기본값은 문서\NHFactory 입니다. 그대로 써도 됩니다.
  2. 2. 이미 쓰던 폴더가 있으면 그 경로를 넣고, 아래 네 칸에 기존 폴더 이름을 그대로 적으세요.
  • - 제작 / 완성본 / 업로드완료 / BGM
  1. 3. 다음 을 누르면 없는 폴더만 새로 만듭니다. 기존 파일은 절대 덮어쓰지 않습니다.

채널 프로필 (.sfprofile)

채널 규칙을 담은 파일입니다: 채널명 · 완료한 편 목록 · 로테이션 규칙 · 스타일 · 엔딩/질문 뱅크.

  • - 처음이면 「새로 만들기」 — 완료 목록이 빈 상태로 시작합니다.
  • - 받은 프로필이 있으면 「프로필 파일 가져오기」 → .sfprofile 선택.
  • - 나중에 바꾸기: 설정 > 채널 프로필 에서 가져오기 / 내보내기.

🔍 잘 됐는지 확인: 왼쪽 위 채널 칸에 채널 이름과 「완료 N편」 이 보입니다.

🧯 막히면

증상 해결
「그 폴더에 쓸 수 없어요」내 계정이 쓸 수 있는 폴더(문서·바탕화면)를 고르세요.
프로필을 가져왔는데 완료 목록이 0편내보낼 때 「완료 목록도 함께 내보내기」 가 꺼져 있었습니다. 다시 내보내 주세요.

🔒 주의: 프로필 파일에는 채널 운영 정보가 들어 있습니다. 공개 저장소에 올리지 마세요.
