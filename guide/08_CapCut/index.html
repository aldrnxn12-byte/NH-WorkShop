08. CapCut 연동 (선택)

⏱ 5분 · 💰 0원 · ✅ 준비물: CapCut PC 버전

프로그램은 자체 렌더 MP4 를 기본으로 만듭니다. CapCut 은 손으로 더 다듬고 싶을 때만 씁니다.

순서

  1. 1. CapCut PC 버전을 설치하고 한 번 실행해 프로젝트를 하나 만들어 저장합니다.
  2. 2. 설정 > CapCut 연동 에서 다시 확인.
  3. 3. 「평문 JSON 으로 보입니다」 가 나오면 초안 만들기를 쓸 수 있습니다.
⚠ 최신 CapCut 은 초안 파일 형식이 바뀌었을 수 있습니다. 「평문이 아니에요」 가 나오면 이 기능은 쓸 수 없고, 자체 렌더 MP4 를 쓰시면 됩니다.

🔒 주의: 프로그램은 CapCut 에 로그인하거나 자동으로 클릭하지 않습니다.
