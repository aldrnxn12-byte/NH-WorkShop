90. 문제 해결

⏱ — · 💰 0원 · ✅ 준비물: 없음

증상별

증상 해결
프로그램이 안 열림01_설치 의 🧯 표(WebView2·백신)
「키가 맞지 않아요」06 의 🧯 표
「AI 사용량 한도에 걸렸어요」1분 뒤 다시 시도하거나 무료 모드(채팅 왕복)로 바꾸세요.
「잔액이 부족해요」06 — 구독과 API 결제는 별개입니다.
음성 엔진 실행 실패03 의 🧯 표
YouTube 「액세스 차단됨」04 — 테스트 사용자 등록이 필요합니다.
자막이 「자리보다 넓어요」 오류그 줄을 짧게 고치거나, 설정 > 레이아웃 템플릿에서 자막 자리를 넓히세요.
렌더가 실패디스크 여유를 확인하고, 설정 > 앱 정보의 로그를 확인하세요.

로그 보내기

설정 > 앱 정보 > 문제 보고용 로그 묶기 를 누르면 zip 이 만들어집니다.

  • - API 키는 들어가지 않습니다.
  • - 이 파일을 담당자에게 보내면 원인을 찾기 쉽습니다.

🔒 주의: 로그를 보내기 전에 화면 캡처에 계정 정보가 찍히지 않았는지 봐 주세요.
