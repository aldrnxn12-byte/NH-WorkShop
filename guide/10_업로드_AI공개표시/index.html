10. 업로드와 AI 사용 공개

⏱ 3분 · 💰 0원 · ✅ 준비물: 완성된 영상

AI 사용 공개가 왜 필수인가

사람처럼 보이거나 실제 사건처럼 보이는 장면을 AI 로 만들었다면, YouTube 는 「변경·합성된 콘텐츠」 공개를 요구합니다.

표시하지 않으면 영상이 내려가거나 수익화에 불이익을 받을 수 있습니다.

프로그램이 해 주는 것

  • - 업로드할 때 AI 사용 공개 = 예 로 보냅니다(확인 창에도 표시).
  • - 영상 설명에 아래 두 줄을 자동으로 넣습니다.
  • - ※この動画は報道・公的資料など公開情報をもとに構成しています。
  • - ※映像にはAIによる再現イメージを使用しています。
  • - 음성 크레딧 音声：VOICEVOX Nemo 도 넣습니다.
  • - 이 문구가 빠지면 ⑥업로드 체크리스트에서 막습니다.

직접 Studio 에서 올릴 때

업로드 화면 → 속성(属性) → 「AI 사용 / 변경·합성된 콘텐츠」 → 예.

🔍 잘 됐는지 확인: ⑥업로드 인스펙터 항목이 모두 ✔ 이고 [업로드 끝남] 이 켜집니다.
