00. 시작하기 — 전체 지도

⏱ 읽는 데 3분 · 💰 0원 · ✅ 준비물: 없음

NH공장은 사건·주제 → 대본 → 음성 → 장면 → 영상(MP4) → 업로드 를 도와주는 Windows 프로그램입니다.

아래 표에서 필수만 하면 오늘 바로 한 편을 만들 수 있습니다.

순서 무엇 필수/선택 돈 가이드
1프로그램 설치필수0원01_설치
2작업 폴더·채널 프로필필수0원02
3AI 무료 모드(채팅 왕복)필수0원05
4음성 엔진·채널 목소리선택(목소리를 넣으려면)0원03
5YouTube 연결선택(앱에서 바로 올리려면)0원04
6AI 유료 API선택(자동으로 돌리고 싶을 때)사용량만큼06
7내 목소리 복제선택서비스에 따라07
8CapCut 연동선택0원08
9BGM 넣기선택0원09

무료로 시작하는 최소 경로

  1. 1. 설치 → 2. 첫 실행 마법사에서 작업 폴더 고르기 → 3. 음성 엔진 내려받기(원하면)

→ 4. AI 는 채팅 왕복(무료) 그대로 두기 → 5. 첫 편 만들기.

🔍 잘 됐는지 확인: 프로그램을 열면 왼쪽 위에 채널 이름이 보이고, 가운데에 후보 카드가 3장 보입니다.

🧯 막히면 → 90_문제해결
