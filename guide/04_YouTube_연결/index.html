04. YouTube 연결

⏱ 5분 · 💰 0원 · ✅ 준비물: 올릴 채널의 Google 계정

프로그램은 공식 YouTube Data API 로만 올립니다. 브라우저를 대신 조작하지 않습니다.

권한 범위는 youtube.upload 하나뿐입니다 — 영상을 올리는 것 외에는 아무것도 하지 않습니다.

순서

  1. 1. 설정 > YouTube 연결 에서 YouTube 연결 을 누릅니다.
  2. 2. 기본 브라우저에 Google 로그인 창이 열립니다. 올릴 채널의 계정으로 로그인하세요.
  3. 3. 한 계정에 채널이 여러 개면 동의 화면에서 올릴 채널(브랜드 계정)을 고릅니다.

여기서 잘못 고르면 다른 채널에 올라갑니다.

  1. 4. 권한 화면에서 허용 을 누르면 프로그램으로 돌아옵니다.

[화면 사진 준비 중 — 채널 선택 화면]

⚠ 심사 통과 전이라면

이 앱은 아직 Google 심사 중입니다. 그래서:

  • - 「확인되지 않은 앱」 경고가 뜹니다 → 고급 → 앱 이름으로 이동.
  • - 테스트 사용자로 등록된 계정만 연결됩니다.

→ 연결하려는 Google 계정 주소를 담당자에게 보내 테스트 사용자 등록을 요청하세요. (연락처: ace@kkuming.kr)

🔍 잘 됐는지 확인: 설정에 「연결됨」 과 채널 이름이 보입니다. 프로필의 채널명과 다르면 빨간 경고가 뜹니다.

올릴 때

⑥업로드 → 제목·설명 확인 → 공개 범위는 처음엔 「비공개(private)」 → YouTube 에 올리기 →

확인 창에서 채널 이름을 한 번 더 보고 올리기.

  • - AI 사용 공개(변경·합성된 콘텐츠)는 항상 「예」로 올라갑니다.

연결 해제 · 권한 철회

  • - 프로그램에서: 설정 > YouTube 연결 > 연결 해제
  • - Google 쪽에서: https://myaccount.google.com/permissions → 해당 앱 → 액세스 권한 삭제

🧯 막히면

증상 해결
로그인 후 「액세스 차단됨」테스트 사용자로 등록되지 않은 계정입니다(위 요청 방법).
다른 채널에 올라감연결 해제 후 다시 연결하면서 동의 화면에서 채널을 다시 고르세요.
「할당량 초과」하루 한도입니다. 내일 다시 시도하세요.

고급 — 내 Google Cloud 클라이언트 쓰기

회사·개인 프로젝트로 따로 쓰고 싶으면 설정에서 내 client JSON 을 등록할 수 있습니다.

만드는 방법은 docs/심사/1_Google설정_따라하기.md 를 참고하세요.
