07. 내 목소리로 만들기 (선택)

⏱ 20분 · 💰 서비스에 따라 다름 · ✅ 준비물: 조용한 방, 마이크

본인 목소리만 복제할 수 있습니다. 다른 사람 목소리는 동의 없이 쓸 수 없습니다.

순서

  1. 1. 설정 > 내 목소리 만들기.
  2. 2. 본인 동의 체크를 켭니다.
  3. 3. 안내 문장을 읽어 녹음합니다(조용한 방, 마이크 20~30cm, 일정한 속도).
  4. 4. 자동 정리 → 복제 → 비교 청취.
  5. 5. 마음에 들면 채널 목소리로 지정합니다.
  • - ElevenLabs 를 쓰려면 가입 후 API 키가 필요합니다(설정 > AI 연결).
  • - GPT-SoVITS 는 내 PC 에서 도는 방식이라 키가 필요 없지만 모델 용량이 큽니다.

🔒 주의: 녹음 파일과 복제 모델은 앱 데이터 폴더에만 저장됩니다. 프로필 내보내기·로그·git 에 들어가지 않습니다.
